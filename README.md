# genai-labor-market-analysis
Analysis of generative AI exposure, occupational change, and labor market development.

# India PLFS microdata

This project uses India’s Periodic Labour Force Survey (PLFS) person-level data for 2018–19, 2021–22, and 2023–24.

The raw PLFS CSV files are stored locally and are not included in this repository because their redistribution terms must be respected.

Official source:
https://microdata.gov.in/NADA/index.php/catalog/PLFS

The analysis will use the person-level file (`perv1.csv` or its equivalent), including occupation codes and survey weights.
